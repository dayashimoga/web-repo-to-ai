# Rule 07: Documentation & Ledger Discipline

1. **Synchronized Living Docs:** Update `PROJECT_STATUS.md`, `IMPLEMENTATION_LEDGER.md`, `TODO.md`, `CHANGELOG.md`, and relevant `docs/*.md` files before closing any subphase.
2. **Append-Only History:** Never delete or overwrite prior history in `CHANGELOG.md`, `TODO.md`, or `IMPLEMENTATION_LEDGER.md`.
3. **Honest Status Reporting:** Use only `NOT_STARTED`, `IN_PROGRESS`, `BLOCKED`, `IMPLEMENTED`, `VERIFIED`, and `ACCEPTED`. Mark `VERIFIED` only with objective test evidence.
4. **Explicit Blocker Disclosure:** If an external credential or environment constraint blocks a task, document the exact blocker and required user action rather than simulating success.
